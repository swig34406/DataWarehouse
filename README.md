# SQL Data Warehouse

A SQL-based Data Warehouse built using a **Bronze, Silver, and Gold layer architecture**.

## Layers
- **Bronze** – Stores raw data from source systems.
- **Silver** – Cleans, transforms, and standardizes the data.
- **Gold** – Contains business-ready data for reporting and analytics.

## Technologies
- SQL
- Relational Database
- ETL / Data Transformation

This project demonstrates a structured approach to building a scalable and analytics-ready data warehouse.
