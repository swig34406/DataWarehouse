# SQL Data Warehouse and Queries 

A SQL-based Data Warehouse built using a **Bronze, Silver, and Gold layer architecture**.

## Layers
- **Bronze** – Stores raw data from source systems.
- **Silver** – Cleans, transforms, and standardizes the data.
- **Gold** – Contains business-ready data for reporting and analytics.

## Technologies
- SQL
- Relational Database
- ETL / Data Transformation

This project demonstrates a structured approach to building a scalable and analytics-ready data warehouse.


 SQL Queries Projects

A collection of SQL queries and database exercises designed to demonstrate practical SQL skills, including data retrieval, filtering, aggregation, joins, subqueries, and data manipulation.

📌 About the Project

This projects contains a variety of SQL queries written to solve common database problems and demonstrate SQL concepts used in real-world data analysis and database management.

The queries cover beginner to advanced SQL concepts and can be used for learning, practice, interview preparation, and portfolio development.

🛠️ SQL Concepts Covered

SELECT statements
WHERE and filtering
ORDER BY
GROUP BY
Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
HAVING
DISTINCT
LIKE, IN, BETWEEN
CASE statements
INNER JOIN
LEFT JOIN
RIGHT JOIN
FULL OUTER JOIN
Self Joins
Subqueries
Common Table Expressions (CTEs)
Window Functions
UNION and UNION ALL
Date and string functions
INSERT, UPDATE, and DELETE
Primary and foreign keys
Constraints
Data cleaning and transformation
